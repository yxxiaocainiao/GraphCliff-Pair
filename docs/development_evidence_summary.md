# 阶段性开发证据：三项机制目前支持什么结论

证据截止：2026-10-05。本页仅使用已经审计的24次三种子交互实验，以及seed42完整26模型消融；两者重叠8个模型，合计42个不重复训练记录。未纳入后续未完成阶段，也未使用官方test结果。完整矩阵完成后，应以其报告更新本页结论。

当前决策：用户已暂停余下训练，转向[仅用现有结果的诊断目标](diagnostic_goal.md)。下文关于完整消融的必要性说明验收范围，不表示队列仍在运行。

**当前证据不支持扩大这套候选方案，也不支持宣称“三板斧有效”。**跨分子注意力在原读出、普通MSE条件下，尚未超过原始单分子基线或参数量匹配的分子对MLP。FPPool和动态Loss有局部改善，但目前只有一个完整消融种子，不能给出稳定的独立收益结论。工程实现已经可运行；继续固定矩阵的科学价值是补齐条件效果的重复性及限制，不是等待结果自动变好。

## 研究对象与原设想的差别

当前实现复用GraphCliff完整短程/长程编码器，在查询和参考分子完成原子编码后、池化前加入双向Cross-Attention；没有替换原短/长程双通道。参考仅来自训练集，按Morgan结构相似度选择Top-1；pair模型预测活性差值，再加回已知参考活性。direct基线直接预测查询活性。因此，pair组合与direct的差距同时包含任务形式和模型结构变化，不能全部归因于注意力。

FPPool是官方池化代码的Morgan-only适配，替换原SAG+MaxMean读出，并增加输出投影；不是官方多指纹模型的完整复现。动态Loss按训练对的真实差值幅度加权，用固定轮次日程逐渐增加权重；它不是根据当前预测误差自适应调权，也不是官方cliff标签权重。实现依据见[设计契约](design.md)和[模型入口](../graphcliff_pair/model.py)。

## Cross-Attention：已有三种子阴性证据，但结论有条件

下表为验证集Cliff RMSE，均值±训练种子间SD，越低越好。这里的Cliff指标是`cliff_mol=1`分子子集的活性RMSE，不是分子对差值误差。

|任务|direct|global|pair_mlp|cross|
|---|---:|---:|---:|---:|
|CHEMBL234_Ki|0.6621 ± 0.0097|0.7694 ± 0.0251|0.7301 ± 0.0209|0.7432 ± 0.0178|
|CHEMBL244_Ki|0.8643 ± 0.0088|0.9996 ± 0.0313|0.9877 ± 0.0382|1.0850 ± 0.0660|

cross相对direct的平均Cliff误差分别增加12.24%、25.54%，相对pair_mlp增加1.79%、9.86%；以上四项比较均为0/3种子改善。相对global，234改善3.41%且2/3种子改善，244恶化8.55%且0/3种子改善。因此，“注意力比最简单的全局差更好”也只在其中一个任务成立，不能代替对更强对照的比较。Overall RMSE相对direct同样恶化，分别为14.24%、25.34%。

这些结果支持[预定额外任务扩展门槛](interaction_preregistration.md)的No-Go判断；不支持注意力在所有读出、Loss、任务或数据划分下普遍无效。来源：[三种子报告](interaction_three_seed_results.md)、[原始精度汇总](interaction_three_seed_results.json)、[24次审计](interaction_three_seed_audit.json)。

## FPPool和动态Loss：目前只能描述单种子的条件效果

以下均为seed42的`处理组 − 对照组`Cliff RMSE，负值为改善。完整比较同时保留有利和不利条件，避免只挑一个组合。

|变化|固定条件|CHEMBL234_Ki|CHEMBL244_Ki|
|---|---|---:|---:|
|原读出 → FPPool|global、MSE|-0.0690|+0.0795|
|原读出 → FPPool|global、动态Loss|-0.0992|+0.0366|
|原读出 → FPPool|cross、MSE|-0.0011|+0.0509|
|原读出 → FPPool|cross、动态Loss|+0.0603|+0.0265|
|MSE → 动态Loss|global、原读出|+0.0247|+0.1192|
|MSE → 动态Loss|global、FPPool|-0.0055|+0.0763|
|MSE → 动态Loss|cross、原读出|-0.0142|+0.0609|
|MSE → 动态Loss|cross、FPPool|+0.0472|+0.0365|
|静态权重 → 动态Loss|global、FPPool|-0.1168|+0.0477|

FPPool在234的global条件下降低Cliff误差，但效果随交互/Loss改变，在244的四个条件下全部恶化。它衡量的是整个读出替换的作用，不能单独证明指纹先验的贡献。动态Loss也未一致改善：例如234的global+FPPool从0.6785降至0.6730，但Overall RMSE从0.6801升至0.6965；相对静态权重的优势仅出现在234的global+FPPool条件。静态对照只覆盖FPPool，不能推广到原读出下的动态日程。

## 失败原因：哪些已经观察到，哪些仍是假设

已经观察到的是：pair方法相对direct的劣势、attention相对MLP的劣势，以及FPPool/Loss效果随任务和组合变化。以下均是待检验解释，现有消融不能确认因果：

- Top-1参考与查询的结构关系可能不足以支持稳定的活性差值学习；需要结合已有参考相似度和误差分布诊断，不能仅凭模型退化认定配对错误。
- 原子级交互可能无法在当前数据量和预算下学到有用匹配；尚未完成足以区分欠拟合与过拟合的学习曲线分析及原子匹配质量诊断，不能直接断言过拟合或注意力失效。
- 差值幅度加权可能放大噪声或弱相似分子对；当前权重定义没有保证它与官方cliff子集一致，性能下降本身不能证明标签噪声存在。
- FPPool替换同时改变信息聚合、参数量和计算开销；已有对照不足以把差距唯一归因于Morgan先验。

## 继续工作还能回答什么

若问题是“现在是否值得追加任务、调参或新增模块”，现有结果已经支持不扩展。若问题是“能否完成原定三个模块的可复现条件消融”，则FPPool、动态Loss及其组合仍需预定重复；交互24次的完成不能替代后两项的三种子证据。[完整消融预注册](three_mechanism_preregistration.md)明确：交互No-Go停止的是额外扩展，保留当前两任务的固定消融与阴性结论。

后续固定矩阵用于判断单种子的方向是否重复、静态/动态差异是否一致，以及三模块是否存在条件依赖；不根据中途结果改配置。正式冻结还需保存权重重放验证预测，之后才能按预定流程作一次test评估。停止剩余计算可以形成有效的阶段性No-Go报告，但不能声称已经完成三个模块的完整三种子验收。

所有结论仅限两项已有开发任务、固定一次数据划分及当前实现。三个训练seed衡量训练随机性，不是三个独立数据划分；目前没有普遍有效性、统计显著性或发表价值的结论。
