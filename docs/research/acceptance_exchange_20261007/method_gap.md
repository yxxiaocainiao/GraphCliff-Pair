# M50：接受交换诊断后的方法缺口与停止决定

2026-10-07。输入为已提交并推送496ca14的M49聚合结果和报告；本阶段不再次解析六张真实数字表，不追加阈值、分组、策略回测或拟合。

## 决定

**完成本轮计划的“证据充分的方法缺口报告”分支；不定义或启动新候选。** 可靠性主线保留，可信最终算法核心仍0。这个决定不否定增强风险的探索收益，也不证明所有部署特征都无法识别有害交换；它说明本轮冻结诊断尚未提供这种识别规则及不同于已有方法的必要操作。

最值得解决的具体小问题现在更清楚：**固定点预测下，增强风险对接受边界的少量改动，其预期损益如何由部署时可用信息识别，而不是仅由评价真值事后解释？** M49为这个问题提供一处实际损失及反向校准证据，但还没有给出可发表的解法。

## 为什么不立即加一个开关

1. **cal收益开关。** 五个cal负向比较在eval均正向，eval两处负向在cal均正向。以此直接作开关有相反证据。没有实际执行这项策略或报告其组合曲线，不以诊断统计冒充回测。
2. **交换人数门控。** 4792@90%只有3进3出确实可部署观察；但单点现象不能确定阈值或证明小交换必坏。这里不搜索阈值、不拿244的其他比例作新分组优化、不把有限支持量换名为新机制。
3. **另拟合一个误差/损益模型或套校准上界。** 这是需要来源、数据合同和比较的既有方法路线，尚未产生任务必要差异。新增学习器不是本次真实失误自动推出的算法；继续拟合会越过当前停止条件。

**一个边界反例（不是算法候选）：** 保持同一组输入、点预测和两风险分数，普通接受{共同分子c，剔除分子n}，增强接受{c，新增分子p}，m=2。世界A里e_n²=4、e_p²=1，净收益为+1.5；世界B里e_n²=1、e_p²=4，净收益为−1.5。可观测名单和分数完全相同，真实标签不同。它说明在不增加分布/误差可迁移假设时，仅凭名单与分数不可能无条件保证每次交换改善；不否认在合理假设下学习条件期望可能有效，也不是新的不可能性理论。

CRC的保证是带假设的期望风险控制，不能写成“这一次接受名单的RMSE必优于普通RF”。本文没有为套用定理而临时截断损失、变换指标、假设分布漂移或新建角色。当前开发cal/eval已经用于多轮检查，也不称从未使用的确认集。

访问异常完整留存：最初尝试CRC的v5 HTML不存在，查arXiv元数据后改为当前v4 PDF；旧PMLR定位失败，未作为文献证据；ICLR CRC PDF超时后从作者arXiv PDF读取相关页。未借二手博客补定理，不声称阅读全部正文。M49报告的科学审查技能来源引用保留，不作为算法依据。

## 改变判断所需的最小证据

未来若继续这个具体问题，应先提供一个明确的部署信息和任务机制，说明为什么能预测交换损益、普通增强RF为何尚不能充分利用，以及与标准条件误差学习/校准的具体差别。用保持名单和模型不变的合成反例先检查等价性与盲点；再冻结一个同信息反证和合法角色合同，列必要成本。M48提出的双端标签依赖审计同样适用，不得直接拼接邻居OOF误差。

这不是本轮已冻结的新实验，也不授权继续遍历旧缓存分组找阳性；本轮不补强ensemble、不增加seed/任务、不恢复组件均衡、配对鲁棒、FP或逐层交互。强对照、原子归因与忠实度、跨seed稳定性和全文仍是投稿资产缺口。没有方法核心时，不能用更完整的诊断代替原创算法或保证二区/三区录用。
