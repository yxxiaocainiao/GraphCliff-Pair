## 停止原因分层

**观察事实：** 三任务seed42同支持量消融比较仅一正两负、宏平均负向；核心实际激活。固定九例有风险敏感性，但候选不表现出统一优于去核心的响应，两任务目标平均变化低于随机平均。均为当前缓存条件下的观察。

**已支持解释：** 候选相对普通5维风险RF的收益不能都归因局部均衡；9维去核心是必要强对照。数值/图身份重放未发现本次明显接口错位，掩蔽确实能改变保存风险输出；敏感性不等于准确风险估计。

**待验证假设：** 等组件平均可能压低有用的高频系列信息；OOF/full参考规模改变或组件定义可能影响泛化。没有单独受控实验支持这些原因，不据此新增模块或换阈值。

**尚不能确定：** 过拟合、标签噪声、参考失真或具体化学机制是否导致退化；跨seed、严格系列/时间独立效应；是否存在可验证的任务适用条件。不能由两任务下降推导均衡普遍无效。

**停止理由与改变判断所需证据：** 当前可定位核心优势不足，唯一限定补证已用完；再次在已见缓存里找阈值/seed/任务会增加选择偏差。恢复需先提出无需查询真值、来源清楚的适用假设或具体修正，冻结强对照及新预算，并在未据此选择的数据条件下验证。不是补更多例图或把234包装成全面有效。
