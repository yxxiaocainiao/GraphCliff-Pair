# M19：单匹配解释监督的结构契约审查

2026-10-05。用户在M18止损后明确要求继续。本轮重新审查一个问题：**共有子结构匹配不唯一时，把一个匹配当作硬解释监督是否合理？** 结果：合成反例可复现；两个实际任务的48个固定训练结构近邻对未达到预先门槛，保留0个候选，结束本轮审查，不启动训练。M18结论保留；算法论文与中科院二区发表目标仍未完成。

## 方法设想与反方检查

AI辅助设想：把单个共有区域换成结构约束下可接受区域集合，训练时减少任意映射给出的硬监督。最简单草案是`L = MSE + λ E_{m∈M(i,j)}[L_explain(a_i,a_j,m,Δy)]`，或只约束所有匹配一致的区域。期望减少区域选择敏感性，同时保持预测质量。这里只写筛查草案，没有新Loss实现或性能主张。

最近方法及反证：

- [ACES-GNN固定源码cliffs.py:194–212](https://github.com/Liu-group/XACs/blob/889b6596913161490dbade6b2203183a9f41c3bf/XACs/cliffs.py#L194)先找一个MCS，再用`GetSubstructMatch`取一个原子映射；监督方式见[M18公式审查](../neighbor_audit_20261005/report.md)。与设想的区别只能暂定位到匹配集合，并未证明足够贡献。
- [解释不变性/等变性研究，NeurIPS 2023](https://arxiv.org/abs/2304.06715v3)已有对模型对称性一致的解释原则及改进方法；不能把“保持解释对称性”称作首次。
- [2026预印本Automorphism-Induced Non-Canonicity](https://arxiv.org/abs/2607.26344v1)直接研究top-k解释的对称性障碍与orbit报告。本文本轮仅核对作者摘要，不能当作完整定理复核；它限制了纯对称报告方案的原创主张。
- [DUE 2024预印本](https://arxiv.org/abs/2403.10831v1)已有不确定性感知解释监督（医学影像）；领域不同不自动使“解释不确定性加权”原创。本轮只读作者摘要，未查完代码/许可/完整公式，所以不存在创新通过结论。

对称等价位置可能有不同编号，但等变模型的归因与归因和可保持相同；这类情况不能直接当作有害标签冲突。只有确有不同环境、目标影响或梯度影响，再优于简单canonicalization/随机映射/匹配平均等替代，才值得考虑方法贡献。对多个匹配平均是常见集合处理运算，不能单凭它支撑论文。没有多人投票或独立专家审核；反方检查由本轮同一助手完成，不能称独立审稿。

## 运行前固定的结构审查

复用已有prepare的seed42 `train_rows/train_pairs`，不重划分、不挑表现好坏的案例。各任务按query/reference排序去重取前24对。仅从所选训练行取SMILES与split，活性、cliff标签、validation与test预测不用于筛查。文件字节哈希用于身份核对；没有解析或评估test标签。

MCS沿用ACES默认价态、ring-only、complete-ring约束，2秒/对；额外使用RDKit原生`StoreAll`收集退化query，每query/分子最多256个匹配，触顶标不穷尽，不能视作全枚举。记录不同原子集合及不同`CanonicalRankAtoms(breakTies=False)`排名多重集；后者是不同环境的充分结构证据，不是完整automorphism或化学因果分类。

**项目继续门槛：** 两任务各至少2对有不同排名多重集证据，且每任务未完成/触顶比例不超过25%；只允许继续定义和核对问题，不能直接通过G3或训练。任一未过就停止，超时保留且不追加预算。规则在结果前写入task_plan；不是期刊标准或统计显著性门槛。

## 五项审查与停止理由

贡献差异：匹配集合可能与ACES单匹配不同，但解释对称/不确定性监督已有近邻，未证明新颖性。公平对照：最低应含MSE、ACES单匹配、canonicalization、随机单匹配、简单集合平均及去不确定性部分；当前均未训练。跨任务重复：两任务结构证据未达项目门槛，不能声称性能优势。解释可信度：仅有合成等变分数检查，不是忠实度或真实化学证据。成本：结构预算小，但ACES可微归因、高阶梯度及集合监督实际GPU成本未知。

**观察事实：** 固定48训练近邻对、43完成、5超时、0不同排名多重集证据；新训练/模型解释/test均0。合成3案例72重编号完整展示，包括未改变监督的对称案例。

**已支持的解释：** 单匹配运算有可复现合成敏感性，但纯对称变化不足以证明Loss冲突；当前小范围实际结构证据不足以支持投入模型训练。

**待验证假设：** 未抽到的cliff对、其他MCS限制或不同靶标中可能存在更强匹配不确定性；即使存在，也未证明导致旧预测退化。这些是未确认假设，不用来追加预算。

**尚不能确定：** 真正冲突比例、对训练梯度/预测的影响、集合监督的收益、解释忠实性、化学有效性和发表潜力。

**停止理由：** 本轮实际证据未过预先结构门槛，且创新边界未清楚；不把技术修补升级成方法论文。可能改变判断的证据只能是独立获得的明确结构冲突与已有机制未覆盖的目标，而不是在这批样本上修改门槛或反复扩样。

## 解释交付与后续研究边界

本候选停止，不建立完整解释系统。合成成功/失败/一般控制完整展示；它们不替代最终模型的分子结构、真值/预测/误差、等大小随机掩蔽与跨seed忠实度。历史模型的有限失败案例及局限继续见[必需解释规范](../framework_review_20261005/explainability.md)。

当前更适合先改变待解决的具体学习问题，再审查算法差异；继续围绕同一底座加通用Loss的预期价值已低。可以在下一轮核查“有限标签下的结构监督是否有可复用且未被SemiMol覆盖的机制”，但本轮未核验它，不把它列成已保留候选，也不自动增加模块或运行训练。总目标保持算法方法论文；需要独立证明贡献和可行性，不能保证分区或录用。
