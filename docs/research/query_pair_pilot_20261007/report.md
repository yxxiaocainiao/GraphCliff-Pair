## 事实、解释与假设

**已观察事实：** joint没有在同容量去关联控制上形成一致增量；对radial的差异也因任务而异。所有固定点预测不变，100%误差相同，差异来自排序接受名单。

**支持的解释：** 这轮结果不足以把“成对几何—活性关联”的耦合必要性写成已验证贡献；普通几何汇总/径向权重已经是不可省略的强替代。不能仅凭四式、相对旧7维的局部涨点或joint赢radial两个任务主张理论完成。

**未验证假设：** 等距时SALI分母抵消是否丢失真实悬崖信息、指纹碰撞是否主导损失、RF是否未稳定利用C，均未作原因认定。不得根据此表追加阈值、改权重或恢复旧模块。

## 解释检查的实际边界

本轮核验的是特征级代数忠实性：Q严格等于各eta*SALI/45之和，亦等于eta均值×SALI均值+总体协方差；查询真值不进入geometry参数。没有把这个加法解释冒充最终RF风险归因。M51的碰撞盲点/查询误差世界反转反例仍保留；本轮没有真实案例图、原子归因、化学机制验证或跨seed稳定性。进一步解释性投入须先有公平对照下可重复的方法增量依据。
