# M51：查询位置与局部活性变化联合建模——四公式理论草案

## 当前判断

提出**一个待检验候选：以查询—两个参考分子的三点几何，调节该参考对活性变化对查询的相关程度。** 暂称“查询相关的成对粗糙度”，仅为描述，不注册新的算法名。四式组成一条可推导、可消融的链；不是四项独立创新。

与M48不同，不使用参考分子预测或OOF残差；与M38不同，不做组件均衡；与M44不同，不做reference最坏情形增量。保留原粗糙度正向证据，不假设必须修好M49两处局部退化。可信最终核心仍0；本候选的数学可定义性、实际效用与投稿贡献是三项不同验收。

## 证据、动机和假设

**已核事实：** 原nbr_disp是k=10训练近邻标签标准差；原sali_mean将这些近邻之间的SALI等权平均。查询影响近邻选择，但在近邻集合不变时，这两项统计不会随查询在集合周围的位置变化。普通5维特征中nn_sim/local_dens只保存最大和平均近邻相似度；固定输入中没有每条参考对与查询的三点关系。

**本项目正向证据：** 三任务seed42增强对普通的六接受率RMSE均值改善约2.08%/2.49%/3.76%；M49的evaluation非全接受13/15正向。这支持保留局部活性变化作为研究信息，不证明以下几何机制解释已有收益。M49两处负向与cal符号不一致也不证明几何造成损失。

**独立假设：** 相同近邻集合与活性差，如果查询更接近某一个参考端点，其“面对两个不同活性端点的竞争程度”可能不同。原粗糙度汇总会丢失一部分这种关联；按三点几何与活性变化联合汇总，可能比先独立汇总再组合更有用。

“端点/竞争”仅指二进制指纹距离关系，不是分子真实三维位置、反应路径、化学机制或活性插值定理。单纯“距离加权有用”已有大量先例；可能的贡献必须落实在这项具体耦合与必要性证据，不能由有限检索未命中来认证。

## 输入与四个相连公式

固定合法reference及原k=10邻居，不改变点模型。二进制Morgan radius2/2048bits；d(a,b)=1−Tanimoto(a,b)，是指纹集合上的Jaccard距离。分子指纹可能碰撞，因此不是分子身份上的严格度量。记a=d(q,i)、b=d(q,j)、c=d(i,j)，参考对P含k(k−1)/2对。沿用已有SALI：S_ij=|y_i−y_j|/max(c,10^−3)，这不是我们的发明。

**式1：查询与参考对的几何相关系数（本次提出的具体运算，原创性待核）。**

\[
\eta_{qij}=\begin{cases}
\dfrac{d(i,j)-|d(q,i)-d(q,j)|}{d(q,i)+d(q,j)},&d(q,i)+d(q,j)>0,\\
0,&d(q,i)+d(q,j)=0.
\end{cases}\tag{1}
\]

二进制Jaccard的正反三角不等式给出0≤η≤1。在查询等于某参考指纹时，该对η=0；当a=b且c=a+b时η=1。同等接近查询但彼此很近的参考对权重较低，不能只用“到查询距离相等”判断竞争。此式依赖c，区别于仅由a、b构成的固定径向权重；没有宣称是新的几何定理。

**式2：保持幅度的联合粗糙度（唯一候选特征）。**

\[
Q(q)=\frac1{|P|}\sum_{(i,j)\in P}\eta_{qij}S_{ij}.\tag{2}
\]

不除以Ση：若再作权重归一化，会抹去整体相关性变弱的幅度，改成另一个问题，本轮不同时测试。Q≥0，且Q≤原平均SALI；这只约束特征幅度，不保证风险降低。参考标签整体平移时Q不变，缩放a倍时Q缩放|a|倍。均值/乘积等基础算子不是原创。

**额外代数审查：** 当c≥10^−3且a+b>0，每对ηS可写成|Δy|/(a+b)×(1−|a−b|/c)。特别是a=b时c完全抵消：在同样查询距离和活性差下，参考对更近不会继续放大该项。这既是抑制原SALI尖峰的可能作用，也是可能抹掉真实悬崖陡峭度的盲点；没有证据判定哪一种占主导。c低于SALI下限时不适用这个抵消式，不能拿极限掩盖指纹碰撞问题。

**式3：区分联合关联与普通两分数组合。**

\[
Q(q)=\bar\eta_q\bar S_q+C(q),\qquad
C(q)=\frac1{|P|}\sum_{(i,j)\in P}(\eta_{qij}-\bar\eta_q)(S_{ij}-\bar S_q).\tag{3}
\]

这是标准总体协方差恒等式，不是新定理。C可正可负，不是风险概率；它把可检验主张收窄为“查询相关几何是否与大的活性变化对齐”，而非两个汇总分数相乘就够。决定性去核心对照为Q_sep=η̄S̄，保留两项均值，去掉成对关联。C用于解释/数学检查，不作为第二个候选训练。

**式4：接入现有误差模型与接受规则（复用，不计原创）。**

\[
z_Q(q)=[\mathrm{GENERIC5}(q),\mathrm{nbr\_disp}(q),\bar S_q,\bar\eta_q,Q(q)],\quad
g_Q=\mathrm{RFfit}(z_Q,|f_{\mathrm{OOF}}-y|),\quad
A_\rho=\operatorname{Bottom}_{\lceil\rho n\rceil}(g_Q(q)).\tag{4}
\]

共9维，固定RF n_estimators200/max_features=sqrt/min_samples_leaf5/random_state42，其余沿用现有协议。排序按风险/canonical/source_row，评价六接受率RMSE均值。RF、OOF绝对误差监督和排序均是现有底座；不暗换e²目标来增加另一因素。式4不保证RMSE最优，M30历史诊断不重做。9维不是创新，必须与同9维对照比较。

## 能证明的差异与不能证明的效果

取三个有限bitset参考{0}、{1}、{2}，标签(0,0,2)。查询A={0,1}、B={0,2}；两者到参考距离的多重集合均为(1/2,1/2,1)，原SALI均值均4/3，η均值均5/9。因此普通距离最大/平均、原活性分散度、η̄S̄均相同；Q_A=4/9，Q_B=8/9，Q_sep均20/27。

这证明Q不总能从原粗糙度与距离汇总及η̄恢复，区别于M48严格退化到局部残差方差。例子是假想bitset，非真实分子；其余GENERIC输入可固定的抽象信息辨识例，不宣称两个真实分子的点预测/rf_var/重原子数必相同。

**强替代也能区分此例：** 普通径向权重κ_ij=T(q,i)T(q,j)的平均κS，在A为0、B为1/6。因此此例没有证明三角权重优于常规查询加权；这一强对照必须保留。不能只对Q_sep赢了便称任务机制独特。

**必留反例：** (a) 相同参考指纹但标签不同，c=0、a=b，η=0；原SALI可很大而Q=0，存在指纹碰撞/重复结构活性冲突盲点。(b) 查询接近一个端点不代表点模型已预测正确，低Q不是低误差保证。(c) 点模型已学会某个强烈变化时，Q仍可能高，不处理M48提出的“已解释变化”问题。(d) 取上述同样bitset，将查询真实误差在A/B间对调，Q排序不变，实际优劣可反转。不附加局部迁移假设，不能证明接受收益必正。

保留nbr_disp和原SALI而非替换，有助于让误差RF仍见到被η压低的变化，但这不是证明盲点已修复。未来若候选只在例外处理后有效，应另登记修订，不能悄悄加分支。
