## 下一次参考预测能回答什么，不能回答什么

如果继续，合理规模是**一个已有full checkpoint、一次针对15个reference的批量预测调用、0新增训练**，用已有15个查询预测核查这些有限对的差值误差与共同偏差。具体模型hash、版本、输入身份、CPU参数、输出重放及墙钟需执行前另冻结，本轮没有加载该checkpoint或调用预测。

这些reference本身在full点模型训练集内，其预测是训练内预测，存在乐观偏差；不能称为OOF误差或无偏见证。查询标签仍只能在诊断末端评价，不能将15对的真值筛选规则变成风险特征构造。即使案例显示某类误差，也不自动训练新风险模型或证明部署可识别。

另一个最低成本理论约束来自M54基础分解。令查询/参考误差为e_q/e_r，c=(e_q+e_r)/2、d=(e_q−e_r)/2，则：

\[
c^2-d^2=e_qe_r.
\]

当训练内参考误差接近0，两项都会接近e_q²/4；仅看共同/差值项占比将趋近各一半。共同项大于差值项，本质上对应两端误差同号，反之对应异号；这是恒等式，不是学会悬崖的因果识别。4个合成误差组合核验通过，本轮没有运行模型估计e_r是否真的小。

因此参考预测只值得用于有限案例和输入合同核验，不能独自解决训练内偏差、同信息强对照或原创运算缺口。若要参考误差也样本外，仍须回到M48/M53的联合排除查询折/参考折审查，不能直接拼接其他折OOF预测。
