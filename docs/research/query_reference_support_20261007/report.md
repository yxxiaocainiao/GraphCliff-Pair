## 事实、解释与假设

**已观察事实：** 234的query-fit reference关系提供87对、74个查询；相同任务M54的query-query配对仅10对。两者是不同图关系，不能将对数增加视为模型性能改善。当前query-reference配对覆盖6.81%/10.04%，未使用标签或预测判断效果。

**支持的解释：** 可以在不加载模型、不碰官方test的条件下，建立一批合法的局部参考索引；数据获取路径并非完全不可行。但它只是少数查询的支持，尤其不能将87对当成87个独立查询。

**未验证假设：** 这些结构对中是否有足够大活性差、是否覆盖高粗糙度误差、固定模型是否学会其中变化、合法参考预测是否比普通局部偏差统计多提供信息，都尚未知。非零样本数量不是统计功效、方法新颖性或可部署识别的证明。

## 下一步的最小成本与边界

若继续同一问题，**先只对这87个已固定对统计活性差子集数量**，再决定是否值得获得参考预测。该步骤仍可0fit/0模型load/predict，但必须另登记查询真值仅用于事后诊断，不能进入风险特征；不重新选对或降低相似度。当前结果不能预报这个子集会有多少对。

如活性差子集值得进一步检查，完整87对只需最多82个不同fit参考的预测，无需先推理全部1755个reference。可从已有full Chemprop获得，新增点模型训练0；但其参考预测是训练内预测，存在乐观偏差，不能称折外误差，不能据此直接开发风险特征或确认创新。模型加载/推理及版本、参数、墙钟和控制需另冻结，本轮均未执行。更小的实际参考子集数量取决于未执行的活性差诊断，不能预先编造。

如果活性差子集仍稀疏或候选仅是普通局部误差/偏差统计，则明确留下方法缺口，不换阈值、加任务或恢复旧模块救结果。此处是最小后续建议，不是新训练队列或已获准的参考推理。
