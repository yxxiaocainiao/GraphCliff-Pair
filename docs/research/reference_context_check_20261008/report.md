## 检查与解释

同查询顺序、585人完整性、7列有限值通过。固定预测文件SHA与原文件相同，mol_size逐值相同；所有查询均满足full的nn_sim与local_dens不小于fold0对应值（容差1e−12）。fixture中的585个查询y为0，未使用作者含查询y依赖的rf_err/dirichlet/lipschitz。另用NumPy数组直接复算六个特征的差值均值/绝对差中位数/P90/最大值，以平均秩的Pearson相关复算Spearman，均与聚合表一致；这项独立数值核对没有重算特征或重新fit。

**观察事实：** 在这一次合法参考替换下，五个参考相关列均发生数值变化；粗糙度两列的秩相关低于此次相似度两列的秩相关。nbr_disp均值上升、sali_mean均值下降，不存在“参考越少，两种粗糙度都必定升高/降低”的统一方向。

**支持的解释：** 仅替换合法参考上下文，就能改变粗糙度值及其跨查询顺序，是后续协议中应明确区分的输入因素。但M66密度适配本来允许特征分布变化；有特征变化不等于误差条件分布变化，也不等于风险模型必然无法迁移。此次结果不能单独判定迁移假设违规。后续若研究粗糙度可靠性，需要验证上下文敏感性与错误的关系，不能仅以更高ESS或一条密度性质代替验证。

**未验证：** 这种上下文敏感性与预测误差或不利接受交换是否相关；参考变化是否导致M66退化；如何区分参考数量与化学组成影响；任何稳定性约束是否提供额外风险信息、区别于既有方法或提高拒答质量。本轮没有读查询真值、调用风险RF或重新计算任何RMSE，因此没有这些答案。

这是对计算输入上下文的替换，不是对真实化学结构/活性的干预。固定了查询、点预测和参数，但参考数量与组成同时改变，辅助RF的训练数据也随之改变，不能称纯规模因果实验。单折、单任务的描述性相关也没有跨seed或显著性结论。

## 决策与交付

M67“输入完全不受此次参考变化影响”的分支不成立；但变化本身不是新算法优势，不据此重开条件加权、补种子、调阈值、再跑两折或增加稳定性模块。可靠性底座保留，可信最终算法核心仍缺。

下一步最小问题是：**这两个已观察到的粗糙度敏感性量，是否与M66已冻结的不利接受交换存在探索性关系？**如继续讨论，应先冻结只读缓存、无分组/阈值/新模型的检验，再决定是否值得设计方法；本轮未执行该关联检查，未产生可部署识别器。
