## 理论与文献边界

成熟重要性加权依赖相应条件响应分布稳定等假设；只观察无标签密度变化，不足以确认本项目的误差条件分布稳定。[Sugiyama等，JMLR 2007官方摘要](https://www.jmlr.org/beta/papers/v8/sugiyama07a.html)明确区分输入边缘变化与输出条件分布不变。本项目响应是OOF绝对误差，而非原分子活性，不能把原QSAR的迁移假设直接套到压缩后的风险证据。

[Bates、Hastie、Tibshirani原始论文摘要](https://arxiv.org/abs/2104.00673)指出CV所估对象与当前已拟合模型的误差并非自然等同，并在OLS等特定设定证明相关结论；本轮只核摘要和元数据，**不把其OLS证明或置信区间保证移植到Chemprop**。这两项基础来源限制解释，不构成新的新颖性综述；本轮没有提出需要与近期方法比较的新算法。

一个简单的源码核对性质：扩大嵌套参考集合时，固定查询的top-k相似度平均值不会降低；但top10邻居活性标准差没有这样的单调性。11个有严格相似度顺序的参考中，full前10个活性为九个0和一个10，子集删除该10后补入0，标准差从3变0；反例方向为full前10全0，子集删除一个0后补入第11个10，从0变3。这是基本次序统计与方差的有限例子，**不是原创定理、不是化学仿真，也不是三个创新点之一**。[check.py](check.py)以纯合成数值核验方向，0估计器fit。

本轮不重复M39的九例/20随机同规模掩蔽：旧检查固定rf_var、用冻结邻居做局部删除，并检查已有风险模型的响应；拟议新检查对同一完整查询批次、更换完整合法参考上下文、重算辅助RF及全部六列，且不调用风险模型。它们分别回答输入上下文敏感性和旧案例风险响应，均不能作为化学干预证明。M30/M31诊断和M60已给反例也不重做。
