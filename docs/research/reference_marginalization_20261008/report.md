# M76：粗糙度参考上下文匹配与风险边际化——一个待反证的应用方法候选

## 问题与依据

小问题：风险RF在折外粗糙度上学习，部署却使用更大参考库产生的粗糙度。能否通过合法的分折参考上下文训练和评分，减少对一次参考库构造的依赖，同时保留粗糙度对误差排序的作用？

事实依据是M67的参考合同差异与M68同查询参考替换：两粗糙度列各503/585变化，秩相关约0.49/0.48。它们只证明输入敏感。M69未支持“变化越大误差越大”，因此本候选**不把敏感性作为拒答分数**。参考变化是否造成错误、该处理是否改善排序均未验证。不是事后定位出某类化学失误，也没有补做M49标签分组。

相对已停候选：不改邻居组件权重（M38），不做密度比（M66），不按敏感性门控（M69），不使用预测锚定活性支持距离（M74），不用邻居OOF预测（M48/M58），不做成对误差预测或稳健交换阈值（M44/M59）。改变的是粗糙度的训练/部署上下文以及评分操作。

## 唯一操作

沿用234/seed42组件开发角色，fit集合D=F0∪F1∪F2，三折468/468/467。查询i∈Fk时，只以Fl（l≠k）作为参考库计算top10粗糙度R_l(i)=(nbr_disp,sali_mean)。G_i保持原5列缓存不变，点预测保持原OOF值，风险监督a_i=|f_−k(x_i)−y_i|。每个查询产生两个7维上下文，权重各1/2：

\[
\widehat L(h)=\frac1{|D|}\sum_{k=0}^2\sum_{i\in F_k}\frac12\sum_{l\ne k}\big[h(G_i,R_l(i))-a_i\big]^2.\tag{1}
\]

用现有RandomForestRegressor拟合一个共享h，沿原200树/sqrt/leaf5/seed42配置，不新增网络、可学门控或风险输入维度。RF的bootstrap和leaf约束意味着样本权重不能让上下文扩展严格等价于原训练；下方增加复制行控制。

部署查询x仍使用固定full Chemprop预测及原full G，仅将R改成三个合法fit折上下文：

\[
s_{\rm ctx}(x)=\frac13\sum_{l=0}^2h(G_{\rm full}(x),R_l(x)).\tag{2}
\]

仍以(s,canonical,source_row)升序，ceil(coverage×n)接受，六比例50/60/70/80/90/100%。平均的是风险分数，不是点预测，也不把分数方差叠入分数。参考库变小、参考组成改变是有意干预，并非免费去噪；没有证明三折上下文独立同分布。

为什么不是普通RF加维度：输入始终7维，改变了训练的上下文分布和部署计算。对于非线性h，h(G,平均R)通常不等于平均h(G,R)，完整参考的top10 R也不等于分折R均值。RF容量足够不代表它能从一个完整参考摘要恢复未提供的所有分折摘要；但这不是实际数据的信息碰撞证明。局部残差统计需要邻居预测，本候选不需要。**平均、增强、RF和粗糙度公式均属成熟操作，不能各计原创。**可争取的应用增量只有“合法参考上下文匹配是否带来可复现的选择性收益”，新颖性仍待进一步查核及实验。

## 有限性质与反例

固定G、h以及三个上下文分数t_l，对任意固定目标a，令s=平均t_l，有精确恒等式：

\[
\frac13\sum_l(t_l-a)^2-(s-a)^2=\frac13\sum_l(t_l-s)^2\ge0.\tag{3}
\]

无需独立性；这是基本平方分解，**不是原创定理**，只比较平均评分和随机选单上下文的评分估计误差。它不比较完整参考评分，不保证接受集RMSE下降；a可取条件平均绝对误差，但本轮未估计它。平均抵消上下文扰动只在扰动方向可抵消时有意义，共同偏差不会消失。

反例：两查询A/B真实绝对误差0/2，完整参考分数0/2正确；分折分数A=(3,3,3)、B=(0,0,0)，平均后3/0。50%接受从A改成B，平方误差从0升到4。式(3)仍成立（这里方差0），因此数学性质不推出部署安全。另一个阈值例R=(0,0,3)、h(r)=1[r≥1]给出h(平均R)=1而平均h(R)=1/3，核对操作不等价。合成例是抽象分数，不冒充真实分子机制。

## 合法性和仍未解决的偏移

训练i∈Fk：G_i及f_−k来自原已核的query-excluded合同；R_l仅依赖Fl的结构/标签，l≠k，且排除canonical相同参考。y_i只进入风险监督，不能进入邻居选择/特征。monitor仍不能充当参考标签池。评价只用fit折标签、固定full预测；全部分数锁定后才读585个evaluation真值。calibration和官方test均不读取。

不调用其他折的邻居预测，避免M58指出的那条回流路径；风险学习整体仍是相关的交叉拟合训练样本，不能声称样本完全独立。标签依赖安全性须在未来执行前按逐行身份重新验收。

本候选只处理R的参考上下文。原G中的相似度/辅助RF方差和点模型训练规模仍有OOF/full差异；参考折组成及大小也不完全相同。不能宣称修复全部分布偏移、提供时间泛化或可靠覆盖率保证。
