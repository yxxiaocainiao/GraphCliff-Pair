## 分层结论与唯一下一步

**观察事实：** 本次候选的平均RMSE超过全部五个对照，并通过预先固定的两个主要比较；部署平均的贡献在80%消融比较中为负。主要比较各比例方向均不由单个最大贡献决定。冻结G、旧R重放、全部36曲线点、36交换行、100%一致及代数响应核验通过；独立标量曲线最大差不超过1e−12。

**支持解释：** 在此任务/缓存/风险seed下，参考上下文处理值得保留进一步核验；复制行本身不足以解释全部收益。平均与增强单独也能改善，故不能断言两者耦合是唯一原因或不可替代算法。

**未验证：** 风险RF随机性稳健性、其他任务、其他Chemprop训练种子、独立数据/时间外推、相对充分Chemprop ensemble的增量、原创性和完整解释。原G及点模型的OOF/full偏移仍在，参考折组成/大小差异未消除。M76平方恒等式是基础数学，不是接受误差保证；正向先导也不能确认中科院二区/三区录用或三项创新。
