## 决策：底线与诊断分开

| 类别 | 后续处理 |
|---|---|
| 查询真实活性/误差/cliff进入推理、角色泄漏、结果身份错位 | 先修复并核验；无有效修复就停止该实验 |
| 对照获得不同点预测/额外信息、许可不明、不可复现 | 不能用于方法结论，补齐合同和证据再比较 |
| 预算上限 | 达到即停；故障/重跑计数，超预算前另行修订提交 |
| 涨点低于3%/5%、不是所有任务改善、胜率少于4/6 | 诊断信息，不自动停止；判断优势范围、稳定性、消融和代价 |
| 组件少于10/20、分子/悬崖少于旧门槛 | 标示支持不足，降低能作的主张；先导可保留困难案例，正式证据须明确适用范围与不确定性 |
| 没有日期/30任务未全覆盖/某模块无效 | 收缩为系列验证或有限任务，公开缺失范围；不伪称时间验证，不强留模块 |

不要求每个部件世界首次提出，也不要求先证明假设有效才准做先导；要求**具体运算或目标差异、合理待验证假设、最近对照及低成本反证**。直接拼接公开模块、照搬sample_weight或分组工具不直接写成新算法。论文贡献允许是可定位的任务针对性改进。

## P0：接下来两个里程碑，结束无尽预检

### M37：定义一个值得试的增量（下一个工作里程碑）

本轮已核对三方法族：官方分组CV、Group DRO、已有选择风险学习。后续只在这三个族及已有粗糙度/UNIQUE对照内补足最接近的实现与差异，不展开第四类模块。基础方法不冒充最新文献综述。

优先考察一个明确问题：**在合法训练参考中，同一化学组件贡献多条近邻时，按分子汇总的粗糙度证据是否应与独立组件支持区分？** 这是待验证假设；M35只证实组件不均衡，未证实风险模型因此失效，M31也没有检验这一具体组件问题。不能将它直接写为已观察的风险瓶颈。

交付一页候选定义：输入、公式/运算、输出、复用位置、与普通增强RF/简单组均衡/Group DRO或最近适用方法的差异、一个去核心消融及解释检查。最多一个候选；若具体差异仍不明确，交付未定核心报告并收束该次审查，不靠加模块填空。本阶段0训练；不得通过重复预检无限延期。

### M38：一次预算固定的先导（候选卡冻结后）

候选具备上述可检验定义即可先导，不要求先拿到大幅阳性。先复用234/244/4792现有合法缓存；候选/去核心/最近可运行对照每任务一次，最多9次风险拟合，普通RF及简单组合复用现有结果；若某臂信息不匹配，按同一协议计入预算重做必要对照，先修订矩阵而不是暗增次数。冒烟只验证接口，不作效果结论。

现有缓存属于已见开发分区，不能称严格组件或时间独立验证。M35临时新角色不能直接借旧点预测冒充其OOF结果。4792保留为困难案例；确实无法形成合法输入时记未完成，不用另一个任务替换它来提高胜率。新分组协议只在明确会改变哪项科学主张时冻结，最多一次结构盲敏感性，不按性能选划分。

主指标仍为已有六接受率RMSE均值；公布全部曲线、全体误差、逐任务差异、消融及成本。新增AURC等指标须预先定义且作为补充，不根据结果换主指标。至少完成一次组件影响/稳定性检查；组件重采样只反映此数据条件下不确定性，不称独立数据重复。

**继续判断写成短评，不以一个数字投票：** 增量是否可识别；相对强对照是否有值得保留的性能、稳定性、困难子群或成本优势；消融是否支持该运算；退化是否局限且可清楚说明。小幅正向可以继续；单次正向也不能宣称稳定有效。若所有宣称优势均无证据，且没有一个预算内、明确可改变判断的补证，停止候选。只允许一轮针对性补证，不能无限改阈值/任务/参数。

## P1：现在开始积累论文材料

方法尚未确认时写问题定义、数据角色、基线、已知限制及图表模板，不写虚构创新和结果。候选冻结后写方法/公式，先导后写消融和失败分析，完整结果稳定后完成全文。

最多三条贡献，每条对应方法差异或实验；写成“具体问题—增量改进—公平对照—重复/消融—解释—成本/限制”。不要求预测本身涨点，接受风险排序/可靠性收益，但须与原先主张一致。

结果基本稳定后，核验三本期刊的范围、机构认可分区年份、费用及投稿要求；二区优先、三区备选、核心另备。匹配期刊不能代替方法证据，核心/三区也不保证录用。时间支线暂缓，系列/组件及assay外分析按实际已验证信息表述。

## 停止与补证记录

停止报告分观察事实、支持解释、待验证假设、未知原因、停止范围/改变判断所需证据；“尚未找到算法”与“算法试验失败”分开。

暂停路线的理由是：在公平强对照下所有预声明贡献均无支持，缺口没有低成本明确补证；不可恢复的有效性问题；或预算耗尽。单个数值门槛、一次失败任务、一次阴性分析不会自动结束发刊目标。若无可投稿方法成果，不自动改成评测论文；另报剩余资产与投稿定位建议。
