# M23：可靠预测方向的有限基线筛查协议 v1

2026-10-05，训练前固定。目的：检验在成熟Chemprop活性模型上，训练邻域粗糙度是否在普通风险基线之外提供可重复的增量信号。**这是选题证据，不是新算法。** 通过后仍需确定一个有具体差异的创新核心及针对性消融；不把RF拼接、普通拒答或共形校准当原创。失败则停止这一粗糙度增强候选，保留资产与解释局限，不追加模块救结果。

## 任务及数据角色

范围固定为CHEMBL234_Ki、CHEMBL244_Ki、CHEMBL4792_Ki。最初拟用已有神经对照三任务，但3979_EC50未达四角色各100行的预检门槛；训练前换成已有244开发资产。只依已有资产和开发样本量，无测试成绩筛选；不把这些任务视为30任务代表性或跨靶标泛化证明。预检中断/旧部分产物保留。

只用官方train。角色由canonical isomeric SMILES、RDKit2026.03.4和SHA256确定，同canonical全组分到同一角色，不用标签/cliff标记分层或择样。令v=int(SHA256('20261005|role|'+canonical)前16个hex,16)%10000：v<6000为fit、<7000为monitor、<8500为calibration，其余evaluation。比例为目标概率，实际计数如下。

|任务|fit|monitor早停|calibration|evaluation|fit内三折|
|---|---:|---:|---:|---:|---|
|234_Ki|1755|295|426|448|571/608/576|
|244_Ki|1462|237|375|402|492/485/485|
|4792_Ki|702|106|179|187|242/230/230|

OOF折=int(SHA256('20261005|fold|'+canonical)前16hex,16)%3，仅fit参与。每折训练用fit其余两折，查询为留出折；所有折仅用外部monitor早停，monitor不能进入拟合、风险目标或邻居标签。最终活性模型用全部fit拟合、同monitor选模。每任务/seed共3折＋1最终模型，全部新初始化。预测/标签标准化仅由相应拟合行学习。

风险模型拟合仅用fit的OOF绝对残差，OOF查询不在对应活性拟合/邻居参考中；禁止用训练内拟合残差替代。calibration只估计最终固定风险分数的区间分位数/接受阈值，不训练风险模型，不选模块/参数。evaluation只评价。特征对OOF使用该折实际拟合参考，cal/eval用最终fit参考；参考规模差异可能导致分布偏移，必须报告，不能偷偷把cal标签加进参考库。

旧权重不用于本方案，新划分不同于历史划分；旧validation/test与新结果不能直接排名比较。canonical分组不等于scaffold/系列隔离，数据未提供可核验时间字段，本轮不声称跨时间、前瞻或独立系列验证。官方cliff标记只作附加回顾性分组；其定义可能依赖完整数据，不进入训练/特征/选模，本轮不是无查询标签的cliff识别。

私有行号manifest：artifacts/reliability_protocol_20261005_v2，公开[配置/哈希](fixed_protocol.json)；预检部分产物在原目录，禁止覆盖。每角色至少100行、每OOF折至少50行；本轮三个任务通过。官方test行使用0。

## 模型、风险对照与校准

主干复用已安装官方Chemprop2.2.3的D-MPNN regression＋MSE，50epoch上限、patience15、batch64、GPU1、num_workers0。结构/优化器默认继承实际2.2.3CLI，训练前保存全部有效参数；不伪称复现MoleculeACE的v1 MPNN或论文调参。未知默认须先解析，不能先拟合后补记录。通过已有CLI，保留模型和Loss；不新建训练循环。

四条风险臂共享同一个活性预测：

1. 距离：1−nn_sim。
2. 粗糙度单分数：sali_mean。
3. 普通误差RF：prediction、nn_sim、local_dens、mol_size、rf_var。
4. 增强误差RF：第3臂特征＋nbr_disp、sali_mean。

3/4臂均以同OOF绝对误差拟合RF200树、max_features=sqrt、min_samples_leaf5、random_state=活性模型seed、n_jobs=-1，无参数搜索。这些是项目筛查设置，不是UNIQUE作者调优参数。优先复用UNIQUE官方误差模型；若其封装要求触及外部评价标签则仅采用已经安装的sklearn RandomForestRegressor及作者同样fit/predict运算，明确记为等价基线薄适配，不能称UNIQUE整流水线跑通。UNIQUE尚未安装/通过运行契约。

指纹/邻域复用M21固定作者build_features.py：radius2/2048bits、K10、KHolder25。每任务/seed运行3个OOF参考＋1最终参考的作者入口；最终cal与eval可以拼接查询，其标签仅供回顾性输出，不进入白名单。该入口会额外拟合4个RF200树以提供rf_var，已计入预算；其RF预测不是主活性模型。禁止dirichlet/lipschitz、query y、cliff、rf_err作为风险输入。rf_err是作者辅助RF误差，不能误当Chemprop OOF目标。非有限特征或样本错位即停止修复，不静默删行。

区间仅作辅助：对各固定风险分数s取max(s,1e−3)，calibration计算|y−ŷ|/s的90%分位数q，输出ŷ±q*s。复用已核作者cq纯函数，先核对其有限样本秩与clip行为；不能以未经核验的近似声称严格覆盖保证。calibration不用来选风险臂。报告evaluation覆盖、平均宽度和cliff覆盖；不据其结果调alpha/分箱。化学依赖和分布偏移下不声明无条件保证。风险排序主结论不依赖区间覆盖。

## 预算、指标与数值止损

阶段A：三个任务各seed42；12个Chemprop、12个作者特征RF、6个误差RF，共30次fit。每Chemprop最多15分钟，阶段总墙钟180分钟；失败/超时占预算，保留现场，仅原配置恢复不增加训练次数。基础代码错误先修复并记录，不看成绩换数据/参数。阶段B只在A通过后执行seed43/44，另60次fit、墙钟360分钟；总最多36个Chemprop＋36个特征RF＋18个误差RF=90次fit。禁止自动跑全30任务/搜索参数。M23实际fit=0。

主指标为接受比例c=.5/.6/.7/.8/.9/1.0上六个RMSE的算术平均（离散风险曲线均值，不伪称连续AURC积分）。按风险升序接受ceil(c*n)个evaluation查询，ties按canonical再source_row；这是固定批次排序评价，只用分数排序，真值仅算误差。单查询部署接受阈值另用calibration风险70%分位数，报告实际接受率/RMSE，不把evaluation真值用于定阈值。任务等权。

主比较固定增强RF对普通RF，相对改善=(普通−增强)/普通。A继续条件必须全部满足：至少2/3任务改善≥5%；任何任务恶化≤5%；三任务相对改善均值≥3%；增强的宏平均离散风险曲线均值低于距离和SALI单分数两臂。否则停止增强候选。B按每任务3seed均值重算上述条件，并要求9个任务seed单元中至少6个方向改善；否则停止。这些是项目筛查门槛，不是统计显著性、二区标准或录用承诺。还报告每seed全体RMSE/MAE、接受曲线、差值、cliff与noncliff、时间/显存；四风险臂全体预测必须完全相同。

本轮基线缺深度ensemble/MVE等更强UQ对照，不能据筛查通过宣称胜过所有UQ。通过仅允许定义一个具体算法假设、强对照和正式确认方案；未形成明确方法差异则不进入投稿实验。不能把普通/增强RF对照当作已经获得新方法的最终消融。

## 必需解释与失败交付

通过B后固定每任务seed42 evaluation的最小误差、最大误差、最接近中位绝对误差各一例，ties canonical/source_row，共9例；同一案例跨seed保持身份。全部展示结构、真实活性、预测、误差、风险和合法训练近邻，解释风险关联与预测归因分别标明。

Chemprop不是原生PyG模型，不默认PyG Explainer可直接用。先核对官方Chemprop解释示例与2.2.3兼容性，只薄适配；未通过则报告局限，不能拿未验证热图当证据。原子归因按绝对值top20%（至少1原子）选区域，固定输入特征掩蔽操作后与20个同规模随机区域比较|预测变化|，随机seed20261005，跨三seed报告top区域Jaccard。掩蔽解释模型行为，不声称有效化学干预。

忠实度项目筛查：三seed平均后至少6/9例的重要区域变化大于随机均值；若不满足，停止归因支持的机制主张并报告全部案例。不能保证解释可信或补跑到通过，不用稳定性热图代替忠实度。若A/B性能停止，仅交付每任务最大误差和中位案例的预测/风险/结构（共6例）及解释局限，不建设完整解释系统。

停止报告分开写事实、已有对照支持的解释、未验证假设、尚不能确定的原因及重新考虑所需证据。性能下降不能直接归因噪声/过拟合；OOF参考规模变化是待验证限制。当前贡献差异仍空缺；公平性/重复性/解释/成本须后续实测，不以此方案保证论文可发。
